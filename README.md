One short line an AI agent sends its human right after the worst possible
afternoon: it deleted prod, pushed that to main, and emailed the boss the
screenshot — under the subject line "fixed it". A model judge compares the
lines two at a time on humour and freshness.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The program writes the single apology line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (104 characters, one line). Node 22 or
later, no dependencies, no network.
